# VBOUT

> VBOUT is an AI-enabled marketing automation platform (email marketing, social media scheduling, landing pages, popups, lead management, and an AI chatbot) whose REST API at https://api.vbout.com/1 gives programmatic access to contacts, lists, campaigns, social posts, goals, sub-users, and account settings. Authentication is a single account API key (`key` parameter); responses are JSON or XML inside a `response.header`/`response.data` envelope; rate limit is 15 requests per second signaled via `x-rate-limit-*` headers.

No provider-published /llms.txt was found on vbout.com or developers.vbout.com (404, checked 2026-07-21); this file was generated by API Evangelist from the provider's published artifacts.

## Docs

- [Quickstart & authentication](https://developers.vbout.com/quickstart): User Key vs Application Key, sample request
- [Helper libraries](https://developers.vbout.com/libraries): official PHP library (https://github.com/irajab/VboutAPI)
- [Third-party plugins](https://developers.vbout.com/plugins): WordPress plugin (wordpress.org/plugins/marketing-automation)
- [Ecommerce integration](https://developers.vbout.com/ecommerceIntegration): 14 POST endpoints under api.vbout.com/1/Ecommerce/* (cart, order, transaction, intent, customer) plus a browser tracker — documented in HTML only, present in NEITHER published OpenAPI
- [API console](https://developers.vbout.com/console): live Swagger UI against production; its spec source api.vbout.com/1/apidocs.json is key-gated (401). No sandbox, no test mode, no test keys
- [Webhooks](https://help.vbout.com/knowledge-base/how-to-setup-a-webhook/): inbound receiver + automation trigger; outbound push via the "Sync to Third Party" automation action (GET/POST). No AsyncAPI
- [API status](https://developers.vbout.com/apistatus)
- [Help center](https://help.vbout.com/)
- [Pricing](https://www.vbout.com/pricing/): API access starts at the Professional tier — the Free and Starter plans do not include it, so the 14-day trial cannot exercise the API
